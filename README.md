# DELONG Construction Science & Technology - Website

This is a static bilingual-ready corporate website for DELONG Construction Science & Technology Sdn. Bhd.

## Publish free with GitHub Pages

### Easiest route: project site
1. Create a **public** GitHub repository, for example `delong-website`.
2. Upload **all files and folders inside this package** to the repository. Keep `index.html` in the repository root.
3. Open **Settings -> Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Your site will be published at:
   `https://YOUR-GITHUB-USERNAME.github.io/delong-website/`

GitHub says Pages is available with GitHub Free for public repositories. Publishing can take a few minutes after changes are pushed.

### Cleaner URL: user/organization site
If the GitHub account name is available for the company, create a repository named:
`YOUR-GITHUB-USERNAME.github.io`

Then the site is published at:
`https://YOUR-GITHUB-USERNAME.github.io/`

## Files
- `index.html` - main website
- `style.css` - layout and visual design
- `script.js` - mobile navigation and footer year
- `assets/` - project-gallery images extracted from the company profile PDF

## Important
The website uses the contact information and company/project claims supplied in the company profile. Review any client names, certifications, response-time targets, and regulatory statements before publishing if they need to be legally or commercially verified.
